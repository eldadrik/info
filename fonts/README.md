# Font Files

The app expects these canvas fonts:

- `FbPractica` for titles.
- `FbPracticaNarrow` for graph text.

If the fonts are not installed on the workstation, place licensed font files in this folder using one of these names:

- `FbPractica.woff2`, `FbPractica.woff`, `FbPractica.ttf`, or `FbPractica.otf`
- `FbPracticaNarrow.woff2`, `FbPracticaNarrow.woff`, `FbPracticaNarrow.ttf`, or `FbPracticaNarrow.otf`

Do not commit proprietary font files unless the license allows redistribution.
